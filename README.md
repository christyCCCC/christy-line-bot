# Christy P 官方 LINE：中文圖文導覽與自然聊天

藝術家與作品系列兩格的介紹只顯示繁體中文，保留圖片、詳細導讀、自然文字觸發與快速閱讀按鈕。周邊新品、展覽與檔期、購買據點、合作洽詢四格的 postback 仍靜默。沒有每日廣播、push、排程或一般聊天個資蒐集；只有用戶主動要求私人導覽時，提供明確用途的登記格式。

## 內容與來源

- `artist_cards.json`：七張藝術家圖卡，顯示 `text_zh`。
- `artworks_catalog.json`：第1–10件作品，顯示中文名稱、原句與完整 `reading_zh`。
- `about_artist_zh.txt`：核准中文藝術家簡介。
- `welcome_message_zh.txt`：核准中文歡迎顯示稿與測試預覽。
- `about_artist.txt`、`welcome_message.txt`及JSON英文欄位：原始雙語資料保留，不作現行文字輸出。
- `static/gallery/`：使用者原圖副本，不改圖、不裁切；原圖上已印有英文仍保留。

## 觸發

「作品」「畫作」「作品集」「作品介紹」「作品系列」或2：系列圖片、中文詳細概念、十件目錄及按鈕。

「你幫我介紹一張畫作」「可以介紹一幅作品嗎」：先提供第1件原圖、中文原句與導讀，不由普通AI臨時編寫。

「作品1」「介紹第3件作品」「介紹愛會咬人」：指定作品圖文。

「想了解藝術家」「你可以幫我介紹一下藝術家嗎」或1：介紹图片與完整中文簡介。

原有 `christy_p:about`、`christy_p:artworks`、允許的 `christy_p:artist:<key>`、`christy_p:work:<id>` postback 不變；未知或未開放選單靜默。閱讀中「上一件」「下一件」「繼續」沿導覽走；拒絕或改聊日常時退出，不把一般提及作品的敘述當指令。

## 少反問聊天

`chat_style=responsive_low_questions_v3`：預設直接回答並接住對方話題，不以連續反問維持對話，不每句追問「你呢／你覺得呢」。只有資訊不足、必要澄清或對方主動邀請時，才偶爾問一個簡短問題。保留先前核准的疲憊捶背問候作自然例外，同意後不再接力追問力道；安全必要澄清不受一般風格限制。門票後續上下文標明為文化局活動，不與藝術家作品導覽混淆。

## 私人導覽報名

「私人導覽報名」「想報名私人導覽」「導覽報名」「預約導覽」及繁簡體別名會先回傳登記格式：姓名、電話、到場日期、到場時間。請使用者把四项資料填在同一則訊息後直接回傳一對一LINE聊天室。這只提供登記及收件回覆，不自行確定人員、可約日期、時段、費用、名額或藝術家本人到場；不更換任何 Rich Menu 格。

填寫資料由固定程式處理，不交給 AI、不加入聊天記憶、不寫入日誌、資料庫或本機檔案，也不重述姓名電話。原始訊息仍留在 LINE 聊天室，帳號管理員須到 Official Account Manager 聊天查看與人工確認；沒有另行發送管理員通知、Google Sheets 或報名表單。資料用途說明為「資料僅供導覽報名與聯繫使用；導覽是否成立及時間安排，仍需另行確認」。完整資料收件只說「已收到你在聊天室填寫的報名資料」，不說預約成立或已保存到報名系統。

若只填部分欄位，提示缺少欄位名，不重述已填值；不長期暫存部分個資，只保留匿名雜湊流程旗標最多30分鐘。群組或多人聊天室只提示到一對一聊天室登記，避免公開姓名電話。取消填寫僅停止本機引導，不代表取消已確認的預約；「清除對話」一併清除匿名登記旗標，不能宣稱刪除了LINE紀錄。

`/status` 的 `tour_registration_version=private_tour_registration_20261110` 與 `tour_registration_enabled=true` 可確認正式版本。此路由優先於門票及 AI，以免包含入場時間或門票的登記誤觸發邀請函。

## 歡迎來源

`WELCOME_DELIVERY=line_official_account` 時真正 FollowEvent 只驗簽後ACK，不重複發送程式歡迎。原生設定已在LINE後台保存中文，現加入封面原圖；原生歡迎與repo獨立。原生歡迎的設計順序為「先封面圖片、後完整核准中文」，此處不表示後台封面圖片已保存，須另行確認。

「測試歡迎」「歡迎訊息」及既有英文別名 `test welcome`、`welcome message` 以原有 NFKC 正規化後精確匹配，直接回封面原圖與核准中文全文兩則（圖片在先、255字中文在後），不由 AI 判斷、不將偶然相同回覆當觸發，也不是廣播、不補發既有好友。封面為 `static/gallery/welcome_cover_20261108.jpg`，原樣複製、未裁切壓縮。`WELCOME_DELIVERY=webhook` 使用相同兩則作明確設定的程式歡迎備援，不應與原生歡迎並用。

## 安全及可靠性

一次 reply token 只呼叫一次回覆API，每次至多五則圖片或文字訊息；最後一則附quickReply。只允許固定圖庫HTTPS圖片路徑，不產生任意網址。

未知售價、展覽、據點、合作窗口仍明說尚無公開資訊。不恢復旧品牌、不冒充本人、不把关心包裝為個資蒐集。

匿名上下文只暫存記憶體，可清除，不代表刪除LINE或模型供應商紀錄。日誌僅記錄事件型別、圖片數與錯誤狀態，不記憑證或聊天正文。

使用既有Render免費主機；閒置喚醒延遲未因本次文字調整而消除。
